# Lessons, revision program (protocol v2)

Read this before any operations step. One entry per mistake: what happened, the guard that now prevents it, and the guard's kind (check > written rule > memory note). A repeated mistake means its guard failed: replace it with a stronger kind.

| 2026-10-28 | The pod tarball carried the laptop user's uid; git on the pod refused the repository ("dubious ownership") and all three tuning pods failed their prep check. | Build every pod tarball with `tar --uid 0 --gid 0`. Since 2026-11-02 every launcher refuses a tarball with a non-root member before creating a pod (tarball guard, below). | check (launcher) |
